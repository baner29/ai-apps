# ai-apps
Repository full of amazing AI apps and agents

## Apps

| App | What it does | Documentation |
| --- | --- | --- |
| **ShaadiTag AI** | Creates personalized hashtag ideas for Indian weddings from the couple's names and story, so guests have memorable tags for every event | [shaaditag_ai/](shaaditag_ai/) |
| **DoFirst** | Sorts personal and work tasks into a four-quadrant priority matrix and scores each task by due date, impact, importance, and criticality, so you always know what to do first | [dofirst/](dofirst/) |
| **BigBank** | Lets hiring teams create and run technical and case-study interviews: build a question bank, assemble an interview, invite candidates with a link, and review their answers and scores in one place | [bigbank/](bigbank/) |
