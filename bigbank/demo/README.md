# BigBank demos

Short walkthroughs of the BigBank interview platform, at 2x speed.

- `candidate-interview.gif` — the candidate experience: starting an assessment, answering a multiple-choice question, a long-form design question and a Python notebook question, then submitting.
- `admin-studio.gif` — the admin studio: the submitted assessment arriving in the results view.
- `question-bank-upload.gif` — bulk upload of a question bank file: preview of new, duplicate and invalid items, then the import into the bank.
