Run DoFirst anywhere

DoFirst is not tied to one platform. Run it on your own computer, or take it to a managed AI hosting platform. Your tasks live wherever you run it, so pick the home that suits you.

Self-hosted, on your own computer

  • This computer, right now: you are already running the self-hosted edition. It saves tasks to a file on this machine and works offline.
  • Any Windows or Mac computer: install Node.js 18 or later, then run npx degit baner29/ai-apps/dofirst dofirst-app, cd dofirst-app, and npm start. Or clone the repository and run npm start in the dofirst folder.
  • As a command: run npm install -g . once inside the folder, then type dofirst in any terminal.
  • As a desktop app: with DoFirst running, use your browser's Install option (Chrome or Edge), or Add to Dock in Safari on a Mac.

Portable single-file edition

Most managed AI platforms host a single HTML file. DoFirst ships one: the full board and scoring engine in a single file, with tasks saved in the browser on that platform.
